# Multi-Vendor Cart · 多商户购物车与拆单引擎

平台型电商的核心难题：一次下单跨多个店铺，钱怎么算、单怎么拆。
本项目实现了一个完整的**拆单引擎**（`split-engine.js`，纯逻辑，Node/浏览器通用）+ 可视化演示。

## 拆单逻辑

```
跨店购物车
  → 按商户分组
  → 每个商户独立套用：店铺券（自动选满足门槛的最优一张）→ 运费规则（基础费 + 续重，满额免邮）
  → 平台券按各子订单券后金额占比分摊（末单吸收舍入差，保证分到"分"不亏不差）
  → 输出 N 个子订单 + 汇总
```

## 规则细节

- 店铺券：自动选最优（门槛满足前提下减得最多的那张）
- 运费：按券前商品金额判断免邮门槛，重量超 1kg 收续重费
- 平台券分摊：按比例精确到分，**最后一个子单吃掉四舍五入误差**
- 演示数据：3 个商户（数码/家居/食品）、9 件商品、3 种平台券策略

## 引擎 API

```js
const result = SplitEngine.split(cartItems, sellers, platformCoupon);
// result.subOrders[]  — 每个商户一个子订单（含券、运费、分摊、应付）
// result.summary      — 合计（商品总额/各级优惠/运费/应付/子单数）
```

## 运行

浏览器直接打开 `index.html`。
